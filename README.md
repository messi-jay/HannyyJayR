# Professional Developer Portfolio

A sleek, formal, and minimal developer portfolio website built with modern HTML5, CSS3, and JavaScript. Zero external build tools or dependencies required.

---

## 🚀 Quick Start

1. **Preview Locally:**
   - Double-click `index.html` to open it in your browser (Chrome, Edge, Firefox, Safari).
   - Or run a quick local server using Python / PowerShell / VS Code Live Server.

2. **Deploy to GitHub Pages (Free Hosting):**
   - Create a GitHub repository named `<your-username>.github.io`
   - Push these files (`index.html`, `styles.css`, `script.js`) to the `main` branch.
   - Your website will immediately be live at `https://<your-username>.github.io/`!

---

## 🎨 Features

- **Formal & Clean Aesthetic:** High-contrast, executive-ready typography and layout inspired by modern developer profiles, without arcade games, floating stickers, or audio widgets.
- **Dark & Light Mode:** Built-in theme switch with local storage preference memory.
- **Executive Snapshot Card:** Quick overview of your education, specialization, certifications, and current focus.
- **Experience & Education Timeline:** Clean chronological view of roles and milestones.
- **Interactive Skills Filter:** Categorized filter tabs (Languages, Web & Frameworks, Tools, Engineering).
- **Project Showcase:** Cards with descriptions, tech tags, and links to source code / live demo.
- **Engineering Metrics:** High-level summary of contributions and experience.
- **Direct Contact & Copy-to-Clipboard:** Quick 1-click email copy action and functional contact form.
- **Mobile Responsive:** Works seamlessly on smartphones, tablets, and widescreen displays.

## ✍️ How to Personalize

Open `index.html` in your text editor:

1. **Name & Title:** Search for `Your Full Name` and `Computer Engineer & Full-Stack Developer` and update with your information.
2. **Profile Avatar:** Replace the initials `DEV` or uncomment the `<img>` tag and provide your photo (`profile.jpg`).
3. **About Me:** Update the summary paragraphs with your background and goals.
4. **Experience & Education:** Edit the `timeline-item` blocks with your university, degree, certifications, and jobs.
5. **Technical Skills:** Add or adjust the `skill-card` elements and `data-category` attributes.
6. **Projects:** Update the `project-card` titles, descriptions, and repository links.
7. **Contact Information:** Update `your.email@example.com` and social links (GitHub, LinkedIn).
